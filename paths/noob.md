# Path: Noobs

**For:** You have never built with AI, and you may not code. You want to know what an agent is.

**Goal:** Explain an agent, a guardrail, a gate and a context window in plain words.

**Time:** 2 hours for the main steps, about a short sit-down a lab.

## How to work

- Run each lab with --demo and watch the output.
- Read the comments in PART 1. You do not need to read the code.
- In the menu, type one question of your own and see what happens.

## Do these

| Lab | Command | What to do |
| --- | --- | --- |
| 1. The agent loop | `bun run lab 1 --demo` | Start here. The whole idea of an agent is one loop. |
| 2. Guardrails and PHI redaction | `bun run lab 2 --demo` | See private details hidden before the model reads them. |
| 3. Human in the loop gates | `bun run lab 3 --demo` | See the system stop and ask a person. |
| 4. Workflow, one agent, multi-agent | `bun run lab 4 --demo` | Compare three ways to build the same helper. |
| 10. The context budget | `bun run lab 10 --demo` | Learn why the model cannot read everything. |
| 15. Stop conditions | `bun run lab 15 --demo` | See how a loop is told to stop. |

## Optional

You can explain how an agent works to a friend, and you know what can go wrong.
